## 📖 Descrição do Projeto

O SpaceGuard Retrieval Arm é um braço robótico desenvolvido para simular operações de coleta de amostras em ambientes de microgravidade.

O sistema foi inspirado em aplicações reais da indústria espacial, onde braços robóticos são utilizados em satélites, estações espaciais e missões de exploração para manipular equipamentos e coletar materiais remotamente.

O projeto utiliza um Arduino Uno, dois servomotores e um LED de status para representar uma operação simplificada de docking e retrieval.

## 🎮 Guia de Operação

Abra o **Monitor Serial** com velocidade configurada em **9600 baud**.

### Comandos Disponíveis

| Comando | Função                   |
| ------- | ------------------------ |
| U       | Subir braço              |
| D       | Descer braço             |
| O       | Abrir garra              |
| C       | Fechar garra             |
| S       | Exibir status do sistema |

---

## ⚙️ Especificações Técnicas

### Componentes Utilizados

* Arduino Uno
* 2 Servomotores
* 1 LED
* 1 Resistor
* Fonte de alimentação 6V
* Protoboard

### Pinagem

| Componente     | Pino |
| -------------- | ---- |
| Servo do braço | 9    |
| Servo da garra | 10   |
| LED de status  | 7    |

### Alimentação

O circuito é alimentado por uma fonte externa de 6V.

O projeto representa um braço robótico utilizado para operações de coleta de amostras em ambientes de microgravidade.
